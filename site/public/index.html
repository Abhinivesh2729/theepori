FAQ

What is Thee Pori?

A free, open-source AI coding agent for the terminal on macOS and Linux, growing into a software factory that runs many projects with one agent. "Thee Pori" (தீப்பொறி) means "spark" in Tamil.

Is it free and open source?

Yes, MIT licensed. You pay only your model provider, or nothing with Thinai.

What is a software factory?

One agent that runs many projects end to end: code, knowledge, releases and upkeep. The coding agent ships today; the rest is coming next.

What is Thinai?

An Android app that runs AI models offline and shares them over Wi-Fi. Thee Pori can use it so private code stays on your network.

How do I update or uninstall?

Run the install command again to update. To remove: curl -fsSL https://tp.0xabhi.space/install.sh | sh -s -- --uninstall
