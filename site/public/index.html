Up and running in 3 steps

No config files to write. No environment variables to set.

1

Install

Paste the command above into your terminal. It verifies the download's checksum before installing.

curl -fsSL https://tp.0xabby.space/install.sh | sh
2

Add a model provider

Pick Anthropic or OpenAI with the arrow keys and paste your API key. tp checks it, stores it in your system keychain and lets you choose a default model.

tp providers
3

Start coding

Open any project and describe what you want. Or run a one-off task straight from your shell.

cd my-app && tp

Available today

Everything below ships in v0.1 and works in any repository right now.

Your choice of model

Anthropic Claude (default: Claude Opus 5.5) and OpenAI today; Thinai and Ollama next. Switch any time with /model.

You stay in control

Reading is free. File edits and commands ask first, with a diff. Destructive commands like rm -rf, git push or deploys always need a typed “yes”.

Sessions that survive

Saved after every step. Ctrl-C or a crash loses nothing: tp -c resumes. /undo reverts the last turn's file changes.

Knows your project

Follows AGENTS.md / CLAUDE.md, respects .gitignore, detects your test command, and remembers decisions with /remember.

Secrets stay secret

Keys live in your OS keychain, are redacted from logs and never passed to commands the agent runs. .env files and private keys are off-limits.

Cost you can see

Token usage and estimated cost after every turn. Prompt caching cuts repeat input cost; long sessions are compacted automatically.

Plan before you build

tp plan "…" investigates read-only and proposes files, steps, tests and risks. Say “go” to implement.

Code review built in

tp review reviews your uncommitted changes, staged work or a whole branch (--base main), most severe first.

Local-first

A single Go binary. No account, no server, no telemetry. Your code goes only to the model provider you choose.

Questions

Short answers.

What is a software factory?

Running several software products the way a factory runs production lines: one operator that knows every project's goals, code, open work and releases, and moves each forward. Thee Pori's coding agent is available today; the multi-project workspace, project knowledge and lifecycle operations are coming next.

What is Thinai?

An Android app that runs AI models offline on your phone and shares them over your Wi-Fi. Thee Pori can use it as a model provider, so private code never leaves your network and there is no API bill.

What do I need?

macOS 12+ (Intel or Apple Silicon) or Linux (x86_64 or arm64), plus an Anthropic or OpenAI API key. On Windows, use WSL for now. Git is recommended.

Where is my API key stored?

In the macOS Keychain (on Linux, the system keyring, or a private 0600 file). It never goes into a config file. An exported ANTHROPIC_API_KEY or OPENAI_API_KEY also works and takes priority.

Does my code leave my machine?

Only the files the agent reads are sent, and only to the model provider you configured. tp has no server and collects no telemetry.

How do I update?

Run the install command again. It replaces the binary and keeps your settings and sessions.

How do I uninstall?

curl -fsSL https://tp.0xabby.space/install.sh | sh -s -- --uninstall removes the binary. Your settings and sessions are kept; the command prints how to delete them too.

Can I install a specific version?

curl -fsSL https://tp.0xabby.space/install.sh | TP_VERSION=v0.1.0 sh. Use TP_INSTALL_DIR to change the install location.
